# 별결 (Byulgyeol) — 자미두수 수익화 웹앱 프로토타입

> "나만의 자미두수 사용설명서"
> 생년월일시 하나로 12궁·14주성·사화·대한을 계산해, 성격·재물·연애·일의 흐름을 한 장의 명반으로 읽는
> 2030 타깃 모던 에디토리얼 웹앱입니다.

---

## 1. 실행 방법

```bash
# Node 20 이상
cd projects/ziwei-app
npm install
npm run dev       # 개발 서버  http://127.0.0.1:5173
npm run build     # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기  http://127.0.0.1:4173
```

## 2. 화면 흐름

```
랜딩(입력 폼 + 상품 3종)
  └─ [내 명반 열기] / [예시 명반 체험하기]
       └─ 무료 결과
            ├─ 명궁 주성 요약 카드 (이미지 저장 1080×1350 / 공유하기)
            ├─ 인터랙티브 4×4 명반 — 궁 클릭 → 주성·보좌성·사화 해설 패널
            ├─ 올해 재물·연애 맛보기(30% 공개 + 블러 처리)
            └─ [잠금 해제] → 결제 확인 모달(테스트) → 잠금 해제 리포트
                 ├─ 내 인생 사용설명서 4,900원  → 기본 리포트
                 ├─ 프리미엄 12궁 & 운세 12,900원 → 12궁 전체 + 지수 + 대한/유년 + 월별 가이드
                 └─ 두 사람 궁합 9,900원 → 상대방 정보 입력 → 궁합 리포트
```

## 4. 계산 엔진에 대해

- **엔진**: [`iztro`](https://github.com/SylarLong/iztro) 2.6.5 — 자미두수 명반(12궁·14주성·사화·대한·유년)을
  계산하는 오픈소스 라이브러리입니다. 음양력·윤달·시진 보정이 들어 있습니다.
- **음력 입력**: `korean-lunar-calendar` 로 **한국 음력 → 양력** 변환 후 계산합니다(윤달 지원).
  한국 음력은 KST 기준이라 중국 음력과 드물게 하루 어긋날 수 있어, 음력으로 입력한 경우 입력값을
  그대로 표기하고 보정 메모를 남깁니다.
- **용어**: iztro 는 내부 계산을 중국어로 반환합니다. 화면에 중국어가 새지 않도록
  `lib/terms.ts` 에서 12궁·14주성·보좌성·잡성·사화·간지·오행국·밝기·십이신을 100% 한국 통용 표기로
  매핑합니다. (디자인 요소로 쓰인 '命宮' 같은 한자 라벨은 의도된 장식이며, 계산 문자열이 아닙니다.)
- **공궁 처리**: 명궁에 주성이 없으면 전통 기법대로 천이궁(맞은편)의 주성을 빌려 성향을 읽고,
  화면에 "천이궁에서 빌려온 주성"이라고 명시합니다.

## 5. AI 리포트 연결 (다음 단계)

`.env.local` 파일을 만들고 아래를 채우면 프리미엄 리포트 하단의 **[AI로 다시 생성]** 버튼이 살아납니다.

```bash
VITE_AI_PROVIDER=gemini      # gemini | openai | claude
VITE_AI_API_KEY=...
VITE_AI_MODEL=gemini-2.0-flash   # 선택
```

- 현재 상태를 확인하는 함수: `isAiConfigured()`, `readAiConfig()`
- 프롬프트: `buildPrompt({ tier, chart, partner? })` → `{ system, user }`
- 호출: `generateAiReport(...)` → `{ ok, markdown }` (실패 시 로컬 엔진 결과 유지)
- **운영 배포 시**: `VITE_` 값은 브라우저 번들에 노출됩니다. `services/aiReport.ts` 의
  `callProvider()` 한 함수만 자체 서버 프록시 호출로 바꾸고 API 키는 서버 환경변수로 옮기세요.
  (요금 폭탄·키 유출 방지)

## 6. 실제 서비스로 가려면

1. **결제**: 토스페이먼츠 / 포트원(아임포트) 연동. 현재 모달은 UI·상태 전이만 구현된 테스트 결제입니다.
   상품 ID(`basic` / `premium` / `compat`)를 결제 주문명과 1:1로 매핑해 두었습니다.
2. **리포트 저장·재열람**: 현재는 메모리 상태만 사용(새로고침 시 사라짐). Supabase 등에
   `이메일 + 상품 ID + 명반 스냅샷` 형태로 저장하고 매직링크로 재열람하게 하면 CS가 크게 줄어듭니다.
3. **배포**: Vercel / Cloudflare Pages 정적 배포로 충분합니다. 빌드 결과물은 `dist/`.
4. **법적 고지**: 하단에 "의료·법률·투자 판단 근거 아님" 문구를 넣어 두었습니다. 유료 운세 콘텐츠는
   전자상거래법상 청약 철회 제한 고지가 필요하므로 결제 모달 문구를 실제 약관과 맞춰 주세요.
5. **바이럴 루프**: 공유 카드(1080×1350)는 인스타그램·스레드 4:5 규격입니다. 공유 URL에
   `?ref=<명반ID>`를 붙여 유입을 추적하면 광고 없이 성장하는 구조를 만들 수 있습니다.
